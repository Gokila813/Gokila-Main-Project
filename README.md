# Project Title

Diabetes Health Risk Analysis Dataset Clinical and lifestyle factors associated with diabetes status.

## Description

This project focuses on analysing a Diabetes Health Dataset containing 5,000 patient records to understand health and lifestyle factors associated with diabetes status. The data was cleaned and transformed using Python and Pandas by handling missing values, standardizing data, and creating meaningful groups for variables such as glucose, insulin, BMI, and age. The analysis examines clinical factors including glucose, insulin, BMI, age, and heredity, along with lifestyle factors such as exercise, diet, smoking, alcohol consumption, stress, and sleep. Interactive Power BI dashboards were developed to visualize the data, compare diabetic, non-diabetic, and unknown-status groups, identify relationships between key health factors, and present meaningful insights for further analysis and monitoring.
